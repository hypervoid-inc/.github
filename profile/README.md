**The desk.** Every agent gets its own cloud desktop on day one. Files and memory stick around after the chat dies. You can interrupt a turn, correct memory, and read a bounded Activity log of what actually happened.

- **Desktop** — open the screen from any device. Watch it work, grab the keys, or close your laptop. It keeps going.
- **Files** — the thread can die; the files don't.
- **Memory** — read it, correct it, wipe it. It's yours, not a black box.
- **Browser & terminal** — real sites, real shell, isolated sandbox, durable workspace.
- **Email & calendar** — it sends, it schedules. Jobs that run, not reminders that wait.
- **Apps & channels** — Gmail, Notion, Linear, GitHub, HubSpot. Brief it on Slack or Discord like a remote hire.

Once a run is right, freeze it into a workflow or an internal app — next time it follows defined logic instead of rolling the dice again. The harness is ours, on Cloudflare's edge, not a VM per agent. Idle doesn't burn compute, so leaving a dozen running overnight is a plan, not a billing incident.
