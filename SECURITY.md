# Security

If you find a vulnerability in Construct Computer or related services, email **[security@construct.computer](mailto:security@construct.computer)**.

Please do not open a public GitHub issue or discuss the report until we have had a chance to investigate and address it. We aim to respond within 24 hours.

For account, billing, or product support, use [support@construct.computer](mailto:support@construct.computer) or [Discord](https://discord.gg/puArEQHYN9) instead.
